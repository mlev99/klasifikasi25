Tips & Trik Pencarian Usaha
Cara Menulis Kata Kunci
  • Gunakan bahasa sehari-hari, contoh: "jual bensin", "bengkel motor", "warung makan".
  • Untuk usaha dagang, awali dengan kata jual / toko / warung / agen / sewa agar sistem mengarah ke kategori Perdagangan, bukan ke kategori produsen/budidaya bahan mentahnya.
  • Untuk usaha jasa/layanan, gunakan kata jasa / klinik / servis / cukur / salon agar sistem mengarah ke kategori Jasa, bukan ke kategori produksi.
  • Untuk usaha pertanian/peternakan, gunakan kata budidaya, pembudidayaan, ternak, peternakan agar hasil lebih presisi ke kategori Pertanian/Peternakan, bukan ke kategori dagang eceran hasil panennya.
Filter Skala Usaha
  • Centang UMKM untuk memprioritaskan hasil berskala usaha mikro, kecil, dan menengah (rumah tangga, perorangan).
  • Centang Usaha Besar untuk memprioritaskan hasil berskala industri/korporasi besar.
  • Filter ini menyesuaikan urutan hasil — bukan menghapus opsi lain, karena kode KBLI sendiri tidak membedakan skala usaha secara baku.
Manfaatkan Tombol Aksi
  • Gunakan 👍/👎 pada hasil pencarian untuk melatih sistem agar makin akurat ke depannya.
  • Klik Buka di KBLI untuk melihat posisi kode dalam hierarki lengkap.
Syarat & Ketentuan
Terakhir diperbarui: 29 Juni 2026

Dengan menggunakan aplikasi Klasifikasi Baku Lapangan Usaha Indonesia ("Aplikasi") yang dikembangkan oleh Saka Omni Webapps, Anda dianggap menyetujui syarat & ketentuan berikut.

1 Sifat Aplikasi

Aplikasi ini berjalan sepenuhnya di sisi perangkat Anda (client-side) sebagai alat bantu referensi dan pencarian kode KBLI (Klasifikasi Baku Lapangan Usaha Indonesia) dan KBJI (Klasifikasi Baku Jenis Pekerjaan Indonesia). Aplikasi ini bersifat independen dan bukan produk resmi Badan Pusat Statistik (BPS) maupun lembaga pemerintah manapun.

2 Sumber & Akurasi Data

Data klasifikasi (KBLI/KBJI) dapat diperoleh melalui dua cara: (1) diunggah sendiri oleh pengguna dalam format JSON dan diproses secara lokal, atau (2) diunduh secara otomatis dari repositori publik GitHub mlev99/klasifikasi25 melalui CDN jsDelivr saat perangkat terhubung ke internet. Pengembang tidak menjamin kelengkapan, keakuratan, atau kesesuaian data dengan publikasi resmi BPS versi terbaru. Hasil pencarian — termasuk skor kecocokan dan sistem pembelajaran (scoring engine) — bersifat perkiraan/rekomendasi, bukan keputusan final.

Untuk keperluan resmi (sensus, pelaporan statistik, perizinan usaha, dsb), selalu verifikasi kode klasifikasi dengan dokumen resmi BPS atau instansi berwenang terkait.
3 Tanggung Jawab Pengguna
  • Pengguna bertanggung jawab atas keabsahan file data (KBLI/KBJI) yang diunggah ke Aplikasi.
  • Pengguna bertanggung jawab memverifikasi hasil pencarian sebelum digunakan untuk keperluan resmi.
  • Pengguna tidak diperkenankan menggunakan Aplikasi untuk tujuan yang melanggar hukum yang berlaku di Indonesia.
4 Batasan Tanggung Jawab

Aplikasi disediakan "sebagaimana adanya" (as-is) tanpa jaminan apapun, baik tersurat maupun tersirat. Pengembang tidak bertanggung jawab atas kerugian langsung maupun tidak langsung yang timbul dari penggunaan, ketidaktersediaan, atau kesalahan hasil Aplikasi, termasuk namun tidak terbatas pada kesalahan klasifikasi yang berdampak pada pelaporan atau keputusan bisnis pengguna.

4b Fitur Sinkronisasi Otomatis

Versi 1.1.0 ke atas dilengkapi fitur auto-sinkronisasi yang, saat perangkat terhubung ke internet, secara berkala memeriksa pembaruan file JSON di repositori publik github.com/mlev99/klasifikasi25 melalui GitHub API dan jsDelivr CDN. Penggunaan fitur ini tunduk pada ketentuan layanan GitHub dan jsDelivr. Pengembang tidak bertanggung jawab atas ketersediaan atau perubahan layanan pihak ketiga tersebut.

5 Hak Kekayaan Intelektual

Kerangka kerja, tampilan, dan logika Aplikasi adalah hak cipta Saka Omni Webapps. Data klasifikasi KBLI/KBJI sendiri adalah milik dan hak Badan Pusat Statistik Republik Indonesia sebagai penerbit resmi.

6 Perubahan Ketentuan

Ketentuan ini dapat diperbarui sewaktu-waktu. Penggunaan berkelanjutan atas Aplikasi setelah perubahan dianggap sebagai persetujuan atas ketentuan yang telah diperbarui.

Kebijakan Privasi
Terakhir diperbarui: 29 Juni 2026

Kebijakan Privasi ini menjelaskan bagaimana Klasifikasi Baku Lapangan Usaha Indonesia menangani data Anda.

Inti dari kebijakan ini: Aplikasi tidak memiliki server backend milik pengembang. Semua data yang Anda unggah atau hasilkan tetap tersimpan di perangkat/browser Anda sendiri. Satu-satunya permintaan jaringan yang dibuat aplikasi adalah saat memeriksa atau mengunduh pembaruan dari repositori publik GitHub mlev99/klasifikasi25 via CDN jsDelivr — data ini bersifat publik dan tidak mengandung informasi pribadi Anda.
1 Data yang Disimpan secara Lokal

Aplikasi menyimpan data berikut di localStorage browser Anda (tidak diunggah ke server pengembang manapun):

  • File data KBLI dan KBJI yang Anda unggah atau unduh otomatis dari GitHub (dalam format JSON).
  • Riwayat pembelajaran sistem pencarian (scoring engine) dari feedback 👍/👎 Anda.
  • Preferensi tampilan, seperti tema gelap/terang dan status pop-up tips.
  • SHA (hash) file terakhir yang diunduh dari GitHub, untuk mendeteksi pembaruan.
2 Koneksi Jaringan & Pihak Ketiga

Saat perangkat terhubung ke internet, Aplikasi melakukan permintaan jaringan ke:

  • api.github.com — untuk memeriksa metadata (SHA dan ukuran) file JSON terbaru di repositori publik mlev99/klasifikasi25. Tidak ada data pribadi Anda yang dikirimkan.
  • cdn.jsdelivr.net — untuk mengunduh file JSON data klasifikasi (KBLI/KBJI) saat tersedia pembaruan. File ini bersifat publik.

Aplikasi tidak menggunakan Google Analytics, Facebook Pixel, atau layanan pelacak pihak ketiga lainnya.

3 Data yang TIDAK Dikumpulkan
  • Aplikasi tidak mengumpulkan nama, alamat, nomor identitas, atau data pribadi lainnya.
  • Aplikasi tidak melakukan pelacakan (tracking), analitik pihak ketiga, atau pengumpulan data perilaku pengguna.
  • Aplikasi tidak menggunakan cookie untuk keperluan periklanan.
4 Berbagi Data dengan Pihak Ketiga

Aplikasi tidak membagikan data pribadi apapun kepada pihak ketiga. Permintaan jaringan ke GitHub API dan jsDelivr CDN hanya mengambil data klasifikasi publik, tanpa mengirimkan informasi identitas Anda.

5 Keamanan & Kontrol Data

Karena data tersimpan di localStorage browser, keamanan data bergantung pada keamanan perangkat dan browser Anda. Anda dapat menghapus seluruh data tersimpan kapan saja melalui menu Pengaturan → Hapus Semua Data Cache, atau mengelola backup data pembelajaran melalui fitur Backup & Restore.

6 Berbagi Antar Perangkat

Jika Anda menggunakan fitur Backup (Export) untuk menyimpan data pembelajaran ke file, file tersebut sepenuhnya berada dalam kendali Anda — disimpan, dipindahkan, atau dibagikan sesuai keputusan Anda sendiri.

7 Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu mengikuti perkembangan fitur Aplikasi, termasuk penambahan sumber data atau mekanisme sinkronisasi baru. Perubahan akan tercermin pada tanggal "Terakhir diperbarui" di atas.
